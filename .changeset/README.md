# Release notes

Run `pnpm changeset` for user-facing changes and select `poweruptime`.
Write a summary for users, including upgrade steps when necessary.

Use patch for fixes, minor for features, and major for breaking changes.
All parts of poweruptime share one release version. Documentation-only and internal
maintenance changes do not need a changeset.

See [the release guide](../.github/DEVELOPER.md#building--releasing) for beta and stable releases.
